## Description

Forsyningsdata Danmark is an address-first platform for exploring Danish public property and infrastructure context.

For the WebMCP Challenge 2026, the application was extended with browser-native WebMCP tools that let an AI agent resolve a verified address, retrieve structured property, utility and environmental context, surface original sources and limitations, and move the visible human interface to the exact section being discussed.

The challenge build demonstrates 10 WebMCP tools and a human + agent workflow where structured agent actions and the visible website remain connected.

Current live data jurisdiction: Denmark.
The architecture is designed for future country-specific connectors, but non-Danish source coverage is not presented as live in this demo.

Public source code:
https://github.com/HenrikBrixCare/forsyningsdata-danmark-webmcp

Built with WebMCP, Next.js, React, TypeScript, Vercel and Danish public geospatial data.
