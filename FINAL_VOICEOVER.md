# Final English voiceover — WebMCP Challenge 2026

Target duration: about 2:35–2:50 at a calm pace.

## Voiceover script

**0:00–0:15**

Forsyningsdata Danmark starts with one thing the user already knows: an address. Public property and infrastructure data may exist, but it is often fragmented across registries, map layers and local sources. WebMCP lets an agent use the product's own structured actions instead of guessing from the page.

**0:15–0:35**

This challenge build exposes ten WebMCP tools. They cover address resolution, property context, utility and environmental screening, official map layers, source handoff, interface context, and visible actions in the human interface.

**0:35–0:55**

Here I search for Vonsyldsgade 11 in Aalborg. The address tool queries Denmark's official address data and returns a stable access-address identifier. That identifier becomes the common key for the rest of the workflow.

**0:55–1:20**

The agent can now retrieve structured property and utility context. The important part is not just the data. Source names and limitations travel with the result, so the agent has an explicit contract for what is documented, what is only screening, and what still requires an original-source check.

**1:20–1:42**

For example, environmental screening never turns missing or preliminary information into a false no-risk conclusion. If a dataset is not actually queried, the tool says so. Exact drawings, pipe locations, permits and authority decisions are handed back to the relevant original source or human check.

**1:42–2:08**

This is the part I care most about. The agent can open the address profile and focus the exact section it is discussing. Here it moves the visible interface to sewer and stormwater. The agent does not replace the website. The person and the agent are looking at the same workflow and the same evidence.

**2:08–2:28**

Language and data jurisdiction are also separate. I can switch the interface to Italian, while the active data country remains Denmark. That lets an international user work with Danish source data in another language without pretending that Italian source coverage is already live.

**2:28–2:48**

The pattern is designed to scale to country-specific connectors, but this challenge build is deliberately honest about its current scope: Denmark is live, other countries are planned. WebMCP turns a fragmented address-data workflow into structured tools for speed, visible sources and limitations for trust, and a human interface that stays in control.
