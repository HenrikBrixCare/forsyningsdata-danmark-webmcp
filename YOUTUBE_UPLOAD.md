## Description

Forsyningsdata Danmark is an address-first Danish public-data application extended for the OpenAI WebMCP Challenge 2026.

The challenge build exposes 10 structured WebMCP tools so an AI agent can find a verified Danish address, retrieve property/utility/environment context, preserve source and limitation information, hand off to original sources, open the visible address profile, focus the exact section being discussed and change interface language without changing the active data country.

The key idea is a shared human + agent workflow: the agent does not replace the website; it can move the visible application to the same evidence it is using.

Demo address: Vonsyldsgade 11, 9000 Aalborg

Public challenge repository:
https://github.com/HenrikBrixCare/forsyningsdata-danmark-webmcp

Challenge preview candidate:
https://forsyningsdata-danmark-git-webmcp-challenge-2026-tilbudstjek.vercel.app

WebMCP tools demonstrated include:
- find_address
- get_address_overview
- get_utility_overview
- get_environment_screening
- get_follow_up_sources
- open_address_profile
- focus_address_section
- set_interface_language
- get_interface_context

Address/parcel data attribution: (CC BY 4.0) Klimadatastyrelsen via Dataforsyningen.

Built with WebMCP, Next.js, React, TypeScript and Vercel.
